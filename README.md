# 📋 Projeto Lista Dinâmica

Sistema simples desenvolvido em **C#** com o objetivo de demonstrar a manipulação de listas dinâmicas, permitindo adicionar, remover e gerenciar itens em tempo real.

---

## 🚀 Sobre o Projeto

O **Projeto Lista Dinâmica** é uma aplicação que simula o funcionamento de uma lista interativa, onde o usuário pode inserir e remover elementos dinamicamente.

Esse tipo de projeto é fundamental para entender conceitos básicos de programação como:

- Estruturas de dados (listas)
- Manipulação de eventos
- Lógica de programação
- Interação com interface

---

## 🛠️ Tecnologias Utilizadas

- 💻 C#
- 🧰 .NET / Visual Studio
- 🖥️ Windows Forms / Console

---

## ⚙️ Funcionalidades

- ✔️ Adicionar itens à lista  
- ✔️ Remover itens da lista  
- ✔️ Exibir elementos cadastrados  
- ✔️ Atualização dinâmica dos dados  

---

## 🧠 Conceitos Aplicados

Este projeto utiliza conceitos importantes como:

- Estrutura de dados do tipo **Lista**
- Manipulação de entradas do usuário
- Controle de fluxo (condições e loops)
- Organização básica de código

---

## 📂 Estrutura do Projeto

O código está organizado de forma simples, contendo:

- Classe principal responsável pela execução do programa
- Métodos para:
  - Adicionar itens
  - Remover itens
  - Listar dados
- Manipulação direta da lista em memória

---

## 🎯 Objetivo

Este projeto foi desenvolvido com fins educacionais, com o objetivo de:

- Praticar lógica de programação
- Entender como listas funcionam na prática
- Servir como base para projetos mais complexos
